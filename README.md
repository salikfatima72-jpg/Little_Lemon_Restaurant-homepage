# Little Lemon Restaurant Homepage

A simple restaurant homepage built using **HTML5** and **CSS3** as my first web development project. This project was created to practice the fundamentals of front-end development, including page layout, navigation, styling, and responsive design principles.

## Features

- Restaurant landing page
- Navigation bar
- Promotional banner
- Information cards
- Image hover animations
- Custom typography using Google Fonts
- Built using only HTML and CSS

## Technologies Used

- HTML5
- CSS3
- Google Fonts

## Getting Started

1. Clone the repository.

```bash
git clone https://github.com/your-username/Little_Lemon_Restaurant-homepage.git
```

2. Open `Index.html` in your preferred web browser.

No installation or additional software is required.
